# Domain Model — Mooring Simulator Physics

*Source: `initial-problem.md` + standard 2D rigid-body naval mechanics.*

---

## Coordinate System

Top-down 2D world. Origin at any fixed point.

- `x` — horizontal (right)
- `y` — vertical (up, or down for screen-space — [UNKNOWN — decide in design])
- `θ` — heading angle (radians, CCW from +x axis)

All vectors have world-frame and body-frame representations. Body frame: x_body = forward (bow), y_body = port (left).

Force model (only tension, no compression):
```
extension = currentLength - naturalLength
if extension > 0:
    F_mag = k * extension + d * extensionRate
    F_dir = normalize(dockPoint - cleatWorldPos)
    Apply F at cleat → force + torque on boat
```

## Forces Acting on Each Boat

### 1. Wind Force
Computed in body frame using apparent wind angle:

```
apparentWind = rotate(wind.velocity, -boat.heading)  // into body frame
F_wind_long = -C_long * wind.speed² * sign(apparentWind.x)
F_wind_lat  = -C_lat  * wind.speed² * sign(apparentWind.y)
// C_long, C_lat = drag coefficients for bow-on vs beam-on exposure
```

Applied at hull center (or sail CoE — [UNKNOWN — simplified or sail model?]).

### 2. Engine Thrust
Along boat's bow direction:

```
F_thrust = thrustTable[throttle] * (bow_unit_vector)
```

`thrustTable`: maps ThrottleState → Newtons (positive forward, negative astern). Values [UNKNOWN — tunable constants].

Applied at propeller position (approximately stern, on centerline).

### 3. Prop Walk
Lateral force perpendicular to heading, generated by propeller rotation:

```
F_propwalk = propWalk * propEffectTable[throttle] * (port_unit_vector)
```

`propEffectTable`: strongest in Astern, weaker in Forward. `propWalk` sign determines port/starboard walk. Applied at stern.

For catamaran with twin engines: [UNKNOWN — two independent propellers, net walk may cancel or compound depending on throttle asymmetry — verify with user].

### 4. Rudder Force
Requires forward (or astern) boat speed to generate lift:

```
speed_body = dot(velocity, bow_vector)
F_rudder_lat = C_rudder * rudderAngle * speed_body * (port_unit_vector)
```

Applied at rudder position (stern). Creates both lateral force and torque about CoM.

### 5. Mooring Line Tension
Per line: spring force (tension only) + damping, applied at cleat world-position.

Torque contribution: `T = cross(cleatPos - comPos, F_line)`

### 6. Hydrodynamic Drag
Water resistance — resists both linear and rotational motion:

```
// In body frame:
F_drag_fwd = -C_fwd * v_body.x  (longitudinal — low resistance, keel/hull streamlined)
F_drag_lat = -C_lat * v_body.y  (lateral — high resistance, keel/hull broadside)
T_drag     = -C_rot * angularVel
```

C_lat >> C_fwd for a sailboat hull (hard to move sideways).

## Equations of Motion (per timestep)

```
// Sum all forces and torques
F_total = F_wind + F_thrust + F_propwalk + F_rudder + ΣF_lines + F_drag + F_collision
T_total = T_wind + T_thrust + T_propwalk + T_rudder + ΣT_lines + T_drag + T_collision

// Integrate (semi-implicit Euler or RK4)
acceleration    = F_total / mass
angularAccel    = T_total / momentOfInertia

velocity        += acceleration    * dt
angularVel      += angularAccel    * dt
position        += velocity        * dt
heading         += angularVel      * dt
```
