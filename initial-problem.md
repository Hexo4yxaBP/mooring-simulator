# Create a mooring simulator game for sailboats and catamarans.

The application must run in a browser.
It should be as simple as possible in terms of visualization: a schematic representation of the boats, dock, water, and mooring lines, all from a top-down view.
The boat's hull should also display its center of mass.
It should accurately calculate the forces acting on the boat's hull and display its motion.
# Key features:

Place one or more boats in the water near the dock
Set mooring lines or springs: Specify the point on the dock where the mooring line originates and the point on the boat where it is attached. The point on the dock can be anywhere, but the point on the boat can only be selected at the cleat locations (stern, midships, bow). - Set wind strength and direction
Change the rudder position for the selected (active) boat
Set the prop walk parameter for the selected boat
Throttle control:
Neutral
Slow forward
Full forward
Slow astern
Full astern
When simulating the active boat's movement, all forces acting on it must be taken into account: wind strength and direction, rudder position, the boat's center of mass, its contact with other boats and the dock, prop walk, and engine thrust.
